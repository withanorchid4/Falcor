# 恢复方向权重公式

用户要求恢复 `((cosTheta + 1) / 2)^2 + 0.2`，停止用背面 Probe 剔除规避距离矩/方差硬边。

实施计划：删除 shader 中额外的半球 gate，删除 UI 背面剔除开关。朝向继续使用原始表面点 P 到 Probe 的方向，以隔离此次公式变更，不同时改变偏移定义；MagicDawn 的 biased Q 方向差异暂不引入。方向权重开关保留，关闭时为 1。距离矩、基础方差、可见性后端、稀疏采样均保持原逻辑。

旧脚本与快照中的 normalHemisphere 参数仍接受，但不再生效，true 会输出兼容性提示；对外设置固定报告 false，防止旧快照重新启用剔除。预览脚本及防漏光预设停止开启该参数。此改动无需重新 Bake。

验证：编译插件；在已有墙面快照中脚本重放，确认旧参数 true 被禁用，读取选点数据并与公式比较，确认背面 Probe 的方向系数不再为 0。分别渲染距离矩、射线和稀疏路径。仅验证公式恢复，不将重现的硬边误报为已解决。

验证结果：Release 插件已编译安装。`tests/probe_gi/direction_weight_restore.py` 在 6 个已保存选点的 48 个 Probe 上检查 GPU 返回的方向权重，与 CPU 公式最大差 `2.945e-7`；其中 24 个背面样本均保留不低于 0.2 的方向权重。距离矩/射线 × full/screenSparse 四种组合完成渲染，缓存 SHA256 未变，退出码 0。结果位于 `build/probe-direction-restore/validation/`；替换前插件及主 shader 备份在上级目录。旧 `hard_edge_fix.py` 中要求半球剔除生效的断言属于已移除功能的历史实验，由本次恢复公式的验证脚本取代。
