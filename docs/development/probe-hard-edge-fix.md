# 墙面硬边修复实验（2026-09-24）

## 目标与约束

用快照 `20260924-021543-642825` 验证修复：减轻可见性/方差的网格状硬边，同时检查漏光和原本可见的 Probe 贡献。
正式算法改动前先在隔离 shader 运行目录渲染。保留原快照、原始缓存和原始截图。
运行时不增加射线，不采用每个 Probe 四次 Chebyshev；优先保持四次矩读取、一次概率计算。

## 实验顺序

1. 对照原始输出，复用上一轮 GPU 导出的实际 P/N、Probe ID、UV、SH 和射线可见性参考。
2. 先尝试把双线性插值的 t 改为 smoothstep(t)：保持凸组合和矩的统计一致性，使 texel 中心处的一阶导数为零。检查方差/可见性图是否减轻网格硬边，是否只把错误漏光变软。
3. 对照烘焙后矩的温和预滤波（在隔离缓存副本上操作），检查平滑是否扩大漏光。
4. 若仅平滑不能处理主要的墙后明亮 Probe 贡献，尝试对背面 Probe 使用平滑的严格半球朝向权重，去掉包裹朝向权重的背面最低贡献。保持现有可见性计算作为其他遮挡的处理，不把朝向权重等同于完整几何可见性。
5. 依据画面、标记区域与射线参考的误差、相邻像素梯度及新伪影决定采用方案。失败实验不作为默认值接入。

## 验证与接入

- 每版相同相机、曝光、SH 与场景；缓存改动必须写独立副本并标记。
- 对照原图、变体、射线参考并检查三个区域；改动后的 GPU 结果与 CPU 公式核对。
- 若采用运行时新选项，写入 properties/Python 配置和快照；旧方式保持可选，明确 UI 含义。旧 SH/距离缓存应能直接加载。
- 在另一个已烘焙测试场景或视角验证有限值、权重有效性与切换行为。
- 最终编译/部署只包含验证后采用的实现，不覆盖用户缓存；更新使用文档。

## 实验后接入决定

CPU 使用原始 GPU 数据重建误差 1.8e-5 以内。GPU 独立重放确认：仅 smoothstep 重建会使方差/可见性硬边变软，但仍保留暗块与漏光；温和 3×3 矩预滤波的 CPU 对照增加了漏光，因此不接入预滤波。

严格半球方案在三个标记区域消除了这些暗块。采用 `wrappedWeight * smoothstep(0, 0.2, dot(N, normalize(probe-P)))`，保留前方大部分原权重，背面为零，在切平面附近平滑过渡。仍不解决位于前半球、却被其他几何遮挡的 Probe。

正式接口：

- `normalHemisphere`：插件默认 false 兼容旧图；预览脚本默认 true。面板 `Reject back-facing probes`，依赖 Normal direction weight 和 Enable visibility。
- `distanceSmooth`：默认 false，面板第三种 `Smooth moments`；只有 `distanceBilinear=true` 时生效。用于独立对照平滑距离矩，不作为本案例主修复。
- 两者仅运行时生效，序列化到 properties/快照，不改变缓存格式或触发 Bake。旧快照仍按旧行为复现，新属性允许通过 replay override 明确开启。
- 预览脚本默认使用原 Bilinear + 半球剔除；每个 Probe 仍四次矩读取和一次 Chebyshev，新增少量标量算术，无新纹理或射线。

## 已完成验证

成功输出：`build/probe-hard-edge-fix-validation-02/`。

- Release 插件编译成功。
- 312 次 GPU Probe 检查：矩插值误差最大 7.82e-7，朝向权重误差 2.95e-7，归一化权重误差 1.41e-6。
- 新选项关闭时原快照 HDR 最大差异为 0；开关往返恢复也为 0。
- 编译后正式接口的三种组合，与先前隔离 shader 候选输出逐像素一致。
- 同一房间另一相机视角的块状硬边也消失；未增加射线，原用户缓存哈希保持不变。
- 独立双房间测试场景重新烘焙/加载 v3 缓存成功，Point/Bilinear/Smooth、禁用朝向、禁用可见性与 properties round trip 通过。
- 历史测试缓存因元数据不匹配被正常拒绝；后续使用独立目录的新测试缓存，没有绕过校验或覆盖旧缓存。

视觉界限：半球抑制仍不能去除装饰线/墙角的所有漏光。双房间测试的地面依然可能收到位于上半球、但在隔墙另一侧的 Probe 光照；这版未宣称解决该情形。`comparison.png`、`second-view.png`、`fixture.png` 保留了与射线可见性参考的差异。

本次修复不会令原始方差数据本身消失；主修复是阻断背面错误贡献，`Smooth moments` 单独提供方差重建的平滑对照。相同 SH 下墙面变暗主要来自剔除了错误漏光，不应通过增大方差把这些贡献重新引入。
